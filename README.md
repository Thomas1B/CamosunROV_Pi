# CamosunROV_Pi, Raspberry Pi Side

This repo is the Raspberry Pi side of the underwater ROV, it works along side the CamosunROV_STM32 code to operate the ROV.<br>
The Pi receives commands from the user via tether and fowards it the STM32 for motor controls. The Pi receives telemetry and forwards this <br>
along with a video stream to the user.
